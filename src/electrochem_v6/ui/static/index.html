专业数据处理

专业模式使用说明

用于批量处理 LSV/CV/EIS/ECSA/COUPLED 数据。先核对数据列、单位、电极面积与电位基准，再预检并运行。

  1. 先选择一个或多个数据文件，或选择文件夹自动发现数据。
  2. 按需加载参数模板，再勾选处理方式并调整通用参数和模块参数。
  3. 预检后运行处理，并到“处理结果”核对输出文件与质量摘要。

参数说明（简版）
  • target_current: 目标电流点，支持逗号分隔多个值。
  • tafel_range: Tafel 拟合区间，常见格式如 1-10。
  • match/prefix: 文件匹配策略与前缀，用于自动识别数据文件。
  • iR 补偿参数仅在电阻信息可靠时启用。
  • ECSA 参数与测试流程强相关，建议和实验记录一致。
