# 项目工作区与可复现流程实施记录

已实现用户确认的“项目管理简化 + 可复现报告 + 历史复算”，并继续完成结果搜索筛选、项目常用参数模板、异常退出后的任务恢复和项目颜色色块选择。沿用现有计算引擎，保留现有工作区未提交修改。

## 界面变化

- 结果、对比、报告三个独立视图；默认结果按运行分组，就地展开详情。
- 项目设置和文件浏览按需打开，低频存储维护迁入系统面板。
- 区分项目回收站与归档历史筛选；处理新数据有明确导航，不因保存项目而改变处理目标。
- 指标使用名称、单位和有效数字，合并历史别名；源文件名区分同名样品。
- 复算常用参数优先，其他参数折叠；nullable 参数不套默认值。

## 数据与计算

- 运行配方独立持久化至 SQLite，包含完整参数、参数字段版本、输入和辅助依赖指纹、历史键与实际输入映射、父运行关系、软件/公式/计算环境信息及结果清单。
- 单条/整次复算创建新运行与新输出目录；原记录与文件不覆盖。
- 来源预览、提交、排队后计算前均有核查，内容变化须明确接受，输入缺失或依赖变化不会被忽略。
- 上传原 ZIP 可恢复临时目录丢失后的输入；恢复缓存保持相对路径并检查 SHA-256，支持再次复算。
- 精确选择两条历史比较指标、单位、参数、来源、版本和质量；相对变化不以零作分母。
- 新 LSV 运行补全电流密度、手动电位偏移、目标电流插值/受限外推及启用时的 Tafel 公式，公式版本为 1.3。
- FE 无传统历史条目时仍保留运行与报告；原 ZIP/恢复缓存按运行引用保护，项目永久删除同步移除配方。
- 删除历史不会通过整次复算或报告恢复已删结果；仍可操作剩余记录。

## 报告

- 全项目、所选结果、单次运行三个界面范围，另支持接口级指定批次，不沿用 UI 分页上限。
- HTML 与 Markdown 包含结果正文及完整复现附录；图表经过本地路径和栅格文件验证，HTML 嵌入图表，Markdown 配套资源文件。
- 缺失历史证据如实标记，不回填当前默认参数或公式；敏感设置字段脱敏，文本安全转义。
- 使用说明：[项目工作区](../docs/project_workspace.md)。接口见 [OpenAPI](../docs/openapi.yaml)。

## 四项功能补充与最终验收

- 结果搜索与筛选：按样品名或文件名搜索项目全部历史记录，再按类型、起止日期和归档状态筛选；数据库先筛选再分页和计数。切换项目或条件时清理旧选择，迟到请求不覆盖新结果。没有样品历史记录的处理批次在清除筛选后可见，全项目报告不受筛选影响。
- 项目常用参数模板：新建和编辑时可关联已有模板；进入处理前显示参数差异，可应用或保留当前参数。应用后预检失效，保留主数据与辅助输入路径。模板删除后保留关联并提示；SQLite 升级及备份恢复保留关联字段。
- 项目颜色：新建与设置均改为预设色块，并保留自定义取色器；新建默认自动配色，兼容既有项目颜色。
- 异常退出恢复：持久保存排队请求和进程身份，确认进程结束后识别中断任务。未知旧进程须人工确认；活跃进程不能绕过检查。预检、提交和执行时核对输入，支持移动文件重新定位、排队和运行中 ZIP 输入恢复。原任务状态与恢复登记再次核验，跨实例重复提交返回同一任务。新运行及输出不覆盖旧记录和文件，不重发纯聊天请求。
