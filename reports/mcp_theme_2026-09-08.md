## MCP

- 使用官方 Python SDK 维护线 `mcp==1.30.0`，以 stdio 暴露 10 个只读工具，配置 `--allow-write` 后增加处理和报告工具。
- 复用既有 HTTP 服务、任务执行器及科学计算模块；不另启动计算引擎，不调用内置付费模型。
- 桌面持有单实例锁期间原子发布 `desktop-service.json`，每次工具调用重新发现并认证当前服务；退出后清理自己的发现文件，迁移排除该文件。
- 显式 URL 只允许 HTTP 回环地址；禁止代理和重定向。HTTP 路由有固定白名单，输入/输出体积有限额，错误不会回显连接令牌。
- 正式提交前重新预检相同请求，要求 `runnable=true`；输出使用引擎生成的新目录。关闭等待期间仍可读取已有任务，新写入遵循原服务的退出门禁。
- 独立的 `ElectroChem-MCP.exe` 保证 stdin/stdout 用于协议，GUI EXE 不兼作 stdio 服务。安装器也检查仍存活的 MCP 进程，避免覆盖正在使用的程序。

使用方法见 `docs/mcp.md`，中英文内置使用说明、README、客户端与打包说明已同步。
