# Windows 客户端

ElectroChem｜智能电化学数据处理软件提供 Windows 桌面窗口，内部使用 WebView2 显示界面，并通过本机回环地址访问计算服务。处理结果仍可保存到用户选定的目录；客户端数据目录保存项目、设置、会话及恢复信息。

## 安装与启动

安装后打开“智能电化学数据处理软件”快捷方式。源码版先运行 `setup.bat`，再双击 `start.bat`；命令行可运行 `python run_v6.py desktop`。需要浏览器入口时使用 `start_browser.bat`。桌面版与浏览器版仍使用同一套计算流程。

新版程序文件为 `ElectroChem.exe`，安装包为 `ElectroChem-Setup-<版本>.exe`，软件显示名称不再附加 V6。便携版需要保留程序所在的完整文件夹。安装升级沿用原安装目录与软件标识，保留数据；安装程序会更新它创建的快捷方式。若以前固定到任务栏的入口仍指向旧 `ElectroChemV6.exe`，请取消旧固定并从新版快捷方式重新固定。

重复启动会唤起同一数据目录的已有窗口。客户端记住正常窗口大小、位置、最大化状态；显示器变化后会把窗口调整回可见区域。外观、语言、上次项目与助手会话也会恢复；输入文件与实验参数需要重新明确选择。端口改变不会清空客户端偏好。

窗口、托盘、浏览器入口和安装包使用统一的蓝色“智能数据”图标。在支持的 Windows 上，标题栏背景、文字及最小化/最大化/关闭按钮的明暗会随软件当前主题同步；“跟随系统”模式也会同步实际主题。窗口按钮仍由 Windows 绘制，保留最大化还原、拖动及贴靠操作。系统高对比度优先，不支持标题栏自定义配色的系统保留其默认绘制。Windows 系统任务栏整体的外观仍由系统设置控制。

安装包会检查 Microsoft Edge WebView2 Runtime。默认包不内置此依赖，缺失时提供 Microsoft 官方下载页面；完成安装后再次继续。普通 Edge 浏览器不能代替 WebView2 Runtime。离线使用应提前安装 Evergreen Runtime，或使用发布者明确标注已包含 Microsoft 签名离线依赖的安装包。客户端不会静默联网安装依赖。

安装、升级或卸载前，先等待正在执行的任务结束，或在应用中取消任务，然后从托盘退出客户端。安装程序检测到客户端仍运行时会提示关闭，不会强行结束计算进程。

## 文件与后台任务

“客户端 → AI 连接（MCP）”可复制其他 AI 客户端所需的本地连接配置。默认只读，可启用新建处理任务和导出报告；任务与结果仍在当前软件中显示。连接时保留完整程序目录并保持软件运行，详细步骤见 [MCP 说明](mcp.md)。

标题栏使用独立主题背景和分界线，与页面背景区分。页面、列表、弹窗及说明正文的滚动条统一跟随主题，高对比度模式遵循系统设置。

“客户端”菜单可打开设置、数据目录、检查更新及退出。文件可以通过原生选择窗口加入，或拖入 TXT/CSV；随后检查类型与启用状态并重新预检。结果文件旁新增“另存为”，原“打开文件”“打开目录”入口保留。网页生成的 CSV/SVG 和手册示例也使用原生保存窗口。超过 32 MB 的文件应从输出目录复制。

关闭窗口时，若有任务或保存操作，会出现四个选择：“继续使用”“后台继续”“等待完成后退出”“取消任务后退出”。后台继续隐藏到托盘，从托盘可恢复窗口。等待/取消退出被确认后不再接收新操作；不可取消的写入完成后才关闭。该阶段不能撤回退出选择。异常退出仍可使用原有任务恢复功能。

## 数据目录与便携版

- 安装版默认使用 `%USERPROFILE%\.electrochem\v6`；安装目录中的 `installed.marker` 表示安装模式。
- 便携 ZIP/onedir 包带有 `portable.marker`，默认使用可执行文件旁的 `user_data`。解压到可写目录后保留整个文件夹。
- 无标记时默认使用用户目录。两个标记不能同时存在，也不会根据安装目录“是否可写”自动切换模式。
- 高级用户可通过 `ELECTROCHEM_V6_DATA_DIR` 明确指定数据目录。此设置优先于模式标记。

升级不会删除旧版可执行文件旁的 `user_data`。需要迁移时先在客户端核对来源和目标，按提示复制数据。历史记录可能仍引用旧位置的原始文件、报告或图片；迁移应用数据后仍应保留旧目录。迁移不会擅自重写历史路径、记录标识或文件指纹。

## 检查更新

点击“检查更新”后，客户端才会查询官方仓库 `Sunnnnch/electro_data_process_tool` 的 GitHub Releases，显示版本和发布说明。稳定版不会推荐预发布版本；网络不可用、超时或无合适安装包时给出明确状态，不影响已有任务。

下载操作打开固定的官方 Releases 页面，由用户下载安装包。更新检查本身不下载、执行或替换程序；远程元数据也不能证明安装包已通过签名验证。正式发布包应具备有效 Authenticode 签名及配套 `.sha256` 校验文件。安装前核对下载文件，结束任务并退出客户端，再运行安装程序。
