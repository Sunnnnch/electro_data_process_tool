# 7.0.1 Windows 安装与运行验收

本文件用于记录标准、离线和便携包在独立环境的验证。开发机测试、接口模拟、静态依赖检查和成功编译均不能填作“干净系统通过”。验收时记录实际产物 SHA-256，重新构建后应重新确认相关结论。

## 目标与环境

- Windows 10 22H2 x64（build 19045）和 Windows 11 x64；ARM、32 位及其他操作系统不属于本轮正式支持范围。
- WebView2 120+ 是支持门槛；验收需记录实际版本，未实测最低版本时明确保留该限制。
- 使用独立电脑或可还原的虚拟机，初始环境不安装 Python、开发工具或本项目依赖。
- 每个安装/升级/卸载场景从明确快照开始，使用合成数据和独立测试目录；不使用真实实验数据或现有用户工作区。
- 安装权限及安全软件策略以目标组织要求为准，不关闭防护或修改整机策略以获得通过结果。

## 每次执行记录

记录日期、测试人员、系统完整版本、CPU架构、显示缩放、网络状态、账户权限、WebView2/.NET版本、包名和SHA-256、安装日志、自检结果、使用的数据夹具、实际输出、截图及通过/失败/未执行状态。失败保留首轮日志；修复后另记复测，不抹去原记录。
