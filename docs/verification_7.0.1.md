# ElectroChem 7.0.1 功能复核

检查日期：2026-09-08。本报告对应移除“经典桌面”前的 `dist_7_0_1_final` 客户端包及其冻结源码，记录下列验证；后续外观调整以[外观说明](appearance.md)及该次验收记录为准。

## 结论与证据

- 完整回归运行 **1478 项**，其中模型超大响应处理出现 1 项失败；修复后对模型发现、配置、LLM、HTTP 路由及相关界面独立复跑 **176 项**，全部通过。
- 对照当前完整测试清单，**1486 个不同测试均有通过证据，未解决失败 0、跳过 0**。这是完整运行与最后变更模块复测的合并结果，不是另一次单独全套运行。
- 两次运行之间只有模型列表响应读取模块发生产品源码变化；236 个源文件逐一核对。覆盖率合并前已移除该文件的旧覆盖数据，最终代码行覆盖率 **82.84%**。Ruff、Pyright、OpenAPI 解析通过。
- 真实本地服务检查通过；4 并发工作线程完成 8 次上传、40 轮模拟助手对话保存 80 条消息。
- 50 项独立功能检查通过，涵盖项目筛选/模板、任务恢复、重复实验、助手操作卡；真实界面完成数据选择→预检→计算→改参复算→单记录报告，10 份原输出 SHA256 不变。
- 最终 Windows 客户端通过本机模拟模型服务验收：输入密钥自动获取、候选选择、401/404及超大列表提示、保护保存、显式发送的真实 SDK 流式传输、关闭重启后恢复。测试窗口及服务均已关闭。
- 安装包和便携包的版本、图标、SHA256、ZIP CRC、61 个静态资源、双程序内嵌 Python 模块与冻结源码一致；包内无用户数据。

## 修复与新增

1. Tafel 电流或电位缺少可区分跨度时不输出伪斜率；低 R² 的可识别拟合保留诊断值并标记需复核，状态随历史/报告保存。
2. ECSA 非正或平坦电容关系不导出负面积；保留原始拟合与失败原因。合法电流极性和扫序不受影响。
3. 所选结果报告只保留可确认属于该记录的质量明细、计数和结果文件；整运行报告仍保留全量。旧数据缺少归属证据时明确提示。
4. AI 设置输入密钥后自动查询模型列表，支持候选选择、手动填写及刷新。列表查询不会保存新密钥或发送对话；慢响应/过大响应/压缩响应有界处理。

## 使用与验证边界

在“数据分析助手 → AI 设置”选择服务商，核对 Base URL，输入密钥；停止输入约 0.7 秒后自动获取。选择模型并保存；不支持兼容 `/models` 的服务可手填模型 ID。模型可列出不等于支持当前对话接口或具备调用额度。

本次未使用真实供应商密钥、账户额度或付费推理；这些取决于实际服务与账户。科学验证采用解析基准、合成数据及文本夹具，不能替代每台仪器/每种实验条件的校准。产物为本地未签名验收包，未安装或发布程序，也未改动原用户数据。
