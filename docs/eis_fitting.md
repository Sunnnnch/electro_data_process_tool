# EIS 拟合与 KK 一致性检查

本模块提供六种固定拓扑的等效电路、频率窗口、两种拟合权重、局部参数不确定度以及独立的 Lin-KK 一致性筛查。优化收敛、参数可辨识与 KK 一致是不同结论，结果分别保存，不能互相替代。

## 模型、公式与单位

以下 `j=√−1`，`ω=2πf`，`f` 的单位为 Hz；`∥` 表示并联，阻抗单位为 Ω。

| 模型 ID | 拓扑 | 参数 |
| --- | --- | --- |
| `randles_rc` | `Rs + (Rct ∥ Cdl)` | Rs、Rct、Cdl |
| `randles_cpe` | `Rs + (Rct ∥ CPE[Q,n])` | Rs、Rct、Q、n |
| `randles_warburg_rc` | `Rs + (Cdl ∥ (Rct + W))` | Rs、Rct、Cdl、sigma |
| `randles_warburg_cpe` | `Rs + (CPE[Q,n] ∥ (Rct + W))` | Rs、Rct、Q、n、sigma |
| `two_time_constants_rc` | `Rs + (R1 ∥ C1) + (R2 ∥ C2)` | Rs、R1、C1、R2、C2 |
| `two_time_constants_cpe` | `Rs + (R1 ∥ CPE[Q1,n1]) + (R2 ∥ CPE[Q2,n2])` | Rs、R1、Q1、n1、R2、Q2、n2 |

单个并联 RC 支路为 `R/(1+jωRC)`；R/CPE 支路为 `R/[1+RQ(jω)^n]`。双支路模型将两个支路串联后加 Rs，并按 `τ=RC` 或 `τ=(RQ)^(1/n)` 从小到大排列参数和区间。R1/R2 是数学支路标记，不自动赋予 Rct、膜阻抗等物理含义。

扩散模型使用 `Z_W=sigma(1−j)/√ω`，总阻抗为 `Rs+1/[jωCdl+1/(Rct+Z_W)]`；CPE 版本将 `jωCdl` 替换为 `Q(jω)^n`。W 位于 Rct 串联支路内部，不能将 `Z_W` 直接加到原单弧电路外侧。这里采用与 [impedance.py 元件定义](https://impedancepy.readthedocs.io/en/latest/circuit-elements.html) 一致的半无限 Warburg 约定；当前六种拟合电路不含有限长度扩散、感抗或传输线元件。

电阻为 Ω，理想电容为 F，Q 为 `S·sⁿ`（双支路分别使用 n1、n2），n 无量纲，sigma 为 `Ω·s⁻¹ᐟ²`。n=1 时 Q 才等于该理想电容；n 改变也会改变 Q 的量纲。不要将拟合 Q 直接用于 ECSA 电容公式。

## 输入与频率窗口

先核对频率、实部、虚部列和源单位。频率支持 Hz/kHz、阻抗支持 Ω/kΩ，虚部列可声明为有符号的 Z″ 或正值表示的 −Z″。系统转换到 Hz、Ω 和有符号 Z″ 后计算。

`eis_fit_frequency_min_hz`、`eis_fit_frequency_max_hz` 始终是 **Hz 闭区间**，即包含上下端点。空值表示该侧不限；填写时必须有限且大于零，下限不得大于上限。电路拟合与 KK 使用同一选中点集；窗口不会改写源文件，也不会自动删除离群点。保存的 `frequency_selection` 含请求范围、实际范围、选中/排除点数及索引，索引对应从零开始的有效解析数据点。

Nyquist/Bode 显示全部测量点，电路拟合线仅覆盖选中的频率。窗口过窄或未覆盖某个过程的特征频率时，即使线看起来贴合，也可能无法确定其参数。

## 权重、初值与接受条件

`eis_randles_fit` 控制电路拟合，`eis_circuit_model` 选择上表之一。`eis_fit_weighting` 可选：

- `uniform`：最小化 `Σ[(ΔZ′)²+(ΔZ″)²]`，实部与虚部等权。优化中使用公共尺度改善数值条件，不改变该最优解。
- `modulus`：最小化 `Σ[(ΔZ′)²+(ΔZ″)²]/d²`，其中 `d=max(|Z|,median(|Z|)×10⁻⁶,10⁻¹² Ω)`。同一点的实部、虚部共用 d；这不是从仪器测得的噪声标准差。

拟合使用确定性的多初值有界 TRF 最小二乘与解析 Jacobian。正参数采用对数坐标，Rs 使用缩放后的线性坐标；初值来自观测谱的实部跨度、虚部峰与频率分布。初值数和优化状态保留在诊断中。目前未提供用户固定参数或自由电路编辑器。

参数边界包括 `0.3≤n≤1`、`10⁻¹⁴≤C≤1 F`、`10⁻¹⁴≤Q≤10`；电阻和 sigma 使用随阻抗尺度/频段调整的宽边界。边界用于限制求解，不代表所有落在范围内的参数都有物理意义。

`eis_fit_min_r2` 是复数 R² 接受阈值，默认 0.5。复数 R² 以 `Σ|Z−mean(Z)|²` 为分母；同时输出实部、虚部、复数 RMSE、归一化 RMSE及所用权重。数值收敛且达到 R² 阈值仍可能标记“需要复核”，例如参数触边、强相关或双支路未分开。比较多个候选模型时先保持输入点与权重一致；当前不会自动认定最高 R² 的模型最好。

## 参数区间与可辨识性

局部协方差由加权残差 Jacobian 线性化得到，按 `SSE/(2N−P)` 估计方差，再映射回物理参数。单参数近似 95% 区间为 `p±t(0.975,2N−P)×SE(p)`。该做法属于 [SciPy 所说明的局部线性近似](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.html)，不是对复杂电路进行完整概率推断。

区间假设模型局部近似线性、加权后残差独立且具有共同方差，不包含模型选择误差，也不是所有参数同时覆盖的区间。对称区间可能超出物理边界。参数触边、Jacobian 秩亏/病态、残差自由度不足或双支路不可区分时，区间返回不可估计并说明原因；不会用零宽区间代替失败。

`identifiability` 保存秩、条件数、触边参数、强相关参数对及双支路分辨情况。双支路时间常数比小于 3、某支路贡献极弱或 Jacobian 秩亏时会要求复核；这些也是工程判据，不是材料物理分类标准。拟合时间常数超出所选频段也会提示复核。

## Lin-KK：独立的一致性筛查

`eis_kk_check` 可在不开启电路拟合时使用。方法基于 [Schönleber 等（2014）](https://doi.org/10.1016/j.electacta.2014.01.034) 的固定时间常数 RC 展开；实现参考了 [impedance.py 的公开方法说明](https://impedancepy.readthedocs.io/en/latest/validation.html)，采用独立矩阵实现，无新增依赖。

展开形式为 `Z_KK=R0+ΣRk/(1+jωτk)+jωL+1/(jωC)`，τk 在所选频段对应的倒角频率之间对数分布。带符号的 RC 权重及附加 L/C 是诊断基元，不是用户选择的物理电路，不应作为该样品的拟合参数导出解释。

KK 始终使用模值归一化的复数线性最小二乘，与电路的 uniform/modulus 开关独立。扫描有限数量的候选阶数，优先选出同时满足残差与 RC 权重稳定性启发式的最简阶数；否则保留候选中 RMS 最小者供复核。μ 根据正负 RC 权重计算，但不会仅凭 μ 宣告通过；粗网格欠拟合也可能出现低 μ。RC 权重几乎为零时 μ 无定义，诊断会注明。

返回三种状态：

- `consistent`：全部选中输入点的相对复数残差 RMS≤2%、最大残差≤5%，且选阶稳定性满足当前启发规则。
- `review`：有可计算的结果，但残差或 RC 权重稳定性需要检查。
- `unavailable`：数据不足、频段分辨率不足、无效输入或数值问题，无法给出一致性判断。

阈值作为 `thresholds` 保存，并标明 `heuristic`。至少需要 10 个不同的正频率，频段跨度为 2～12 decade。非有限值、非正频率、近乎恒定阻抗会返回明确原因。计算上限为 20,000 个输入点、最多 600 个确定性选取的拟合点及 30 个 RC 基元；**无论是否采样，最终残差与判据覆盖全部选中输入点**。采样数量、原始索引、策略与尝试阶数一并保存，不会把未参与拟合的异常点藏起来。

KK 一致只支持当前有限频带内的数据一致性；不能证明某个等效电路正确，也不能单独证明实验线性、因果性或稳态。边界效应、噪声与频率覆盖不足可能使本来满足 KK 的系统也需要复核。

## 输出与历史复算

开启电路拟合或 KK 后，结果目录包含 `*_EIS_Diagnostics.json` 和 `*_EIS_Residuals.csv`；有可用残差且启用残差图时再生成 `*_EIS_Residuals.png`。JSON 保存模型、接受与复核原因、局部区间、频段选择以及 KK 方法/阈值/采样信息。CSV 每行保留有效解析点索引、频率、观测阻抗、可用拟合值和残差。

电路残差定义为 `Z_observed−Z_fit`，单位为 Ω；KK 残差为除以带小模值保护的 `|Z|` 后的相对值，CSV 使用小数，绘图乘 100 显示百分比。拟合被拒绝或存在可辨识性警告时，可用诊断仍保留并标注状态，不伪装成已确认的参数结果。

本次参数、频段、诊断和公式快照会进入运行记录、历史与可复现报告。公式 schema 从 1.3 升级到 **1.4**：只记录本次开启的电路模型公式及 KK 方法，保存单位、权重、频段和假设。旧记录保留原公式版本；历史复算创建新运行与新结果，不用当前公式覆盖旧报告。
