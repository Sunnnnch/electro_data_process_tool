# 项目工作区、历史复算与可复现报告

项目管理默认打开“结果”，按每次处理分组，展开一条结果即可查看指标、原始数据和关联文件。项目名称、说明、标签等通过“更多 → 项目设置”编辑；“在此项目处理新数据”进入处理页面并选中该项目。保存项目设置不会改变正在编辑的处理任务归属。

点击左侧“新建项目”，在弹窗中输入名称（必填）和说明（可选）；展开“更多设置”可填写标签、选择项目颜色并关联常用参数模板。标签支持英文或中文逗号分隔；颜色可选预设色块或使用自定义取色器，新建时默认自动配色。点击“创建项目”后会自动选中新项目；取消或按 Esc 关闭弹窗不会创建项目。名称重复等保存错误会显示在弹窗内并保留填写内容。

## 三个工作视图

| 视图 | 用途 |
| --- | --- |
| 结果 | 搜索样品或文件名，按类型和日期筛选；按批次查看历史，展开结果；复算并打开运行报告 |
| 对比 | 指定两条同项目、同数据类型的历史记录，对照指标、参数、来源和质量变化；保留原有 LSV 跨样品比较 |
| 报告 | 选择全项目、所选结果、单次处理，导出 HTML 和 Markdown |

结果附近的“包含已归档记录”仅影响历史记录范围；项目列表的“项目回收站”用于查看已归档项目。应用托管文件的存储统计和清理统一放在系统面板。

## 查找项目结果

结果页搜索框匹配样品名或文件名；“筛选条件”可限定处理类型和起止日期。搜索与筛选作用于项目的全部历史结果记录，显示的匹配总数不受当前已加载页数限制。开始和结束日期都包含当天记录，按历史保存的本地日期比较；日期范围填反时会提示修正。更换筛选条件后从第一页重新加载。“清除筛选”移除搜索、类型和日期条件，归档记录仍由“包含已归档记录”控制。尚未形成样品结果记录的处理批次（例如部分 FE 运行）在清除筛选后显示；全项目报告始终按其独立范围生成。

## 关联并应用常用参数模板

新建项目或编辑项目信息时，可选择已有内置模板或自己保存的模板。保存关联只修改项目信息；不应用模板，也不改变正在编辑的处理参数。

点击“在此项目处理新数据”后，关联模板的项目先显示当前参数与模板的差异。选择“应用模板并进入”才修改处理参数，并使原预检失效；选择“保留当前参数进入”仅切换项目。已选择的主数据、文件夹和辅助文件（产品表、峰方法文件、iR 补偿 EIS 文件）都会保留，不被模板中的旧路径替换。

项目关联的是模板名称。模板被修改后，下次预览使用其最新内容；已经保存的历史运行参数不受影响。模板被删除或不可用时，会保留项目中的关联名称并提示重新关联，此时可保留当前参数继续，不能应用缺失模板。选择“不关联模板”可解除关联。

## 从历史结果复算

1. 展开结果，选择“复算此结果”，或在批次详情选择整次处理复算。
2. 选择使用原参数或修改参数。预检展示参数变化、输入检查结果和计算版本。
3. 输入文件移动后可重新定位；文件内容发生变化时，必须明确选择接受新内容。
4. 预检通过后开始复算。任务完成后刷新项目结果；新记录保留其原运行和原结果关系。

复算始终创建新的运行编号和输出目录。提交时重新预检，排队后开始计算前再次核对全部实际输入与辅助依赖的 SHA-256，防止在预览后悄悄换用其他数据。

ECSA 单条结果复算包含该样品的多个扫速文件；LSV iR 补偿包含当时匹配的 EIS 文件；COUPLED/FE 复算使用完整定量表及方法、信号依赖。修改参数导致依赖范围变化时，需要回到处理页明确选择新的完整输入。

上传 ZIP 的临时目录清理后，可以从保存的原 ZIP 恢复数据，保留包内相对路径。恢复文件位于应用数据目录的 `runs/replay_sources`，每次使用均核验指纹。原 ZIP 变化时不会将它当作原件。已有完整校验缓存时，原 ZIP 丢失也可使用该缓存。

## 异常退出后的任务恢复

项目页的“任务恢复”入口显示待恢复数量，覆盖全部项目及尚未分配项目的排队任务。重新启动只识别中断任务，不自动重跑。

1. 打开“任务恢复”，选择“查看并预检”。系统核对原任务的进程身份、已保存参数及输入。
2. 文件移动后可填写实际位置并重新预检；内容改变时需明确选择接受变化。
3. 预检通过后点击“恢复为新任务”。创建新的任务、运行编号和输出目录，保留原有记录及文件；可以关闭弹窗，后台任务继续执行。

系统结合主机、进程编号和进程启动身份判断任务是否中断，不以运行时间长短判断。仍在运行的任务不会恢复；旧记录缺少进程身份时，需要先人工确认执行原任务的程序已经关闭。恢复表示重新计算，不是从某个计算点继续执行。

旧排队请求可能未保存完整参数或输入指纹，预检会明确说明并展示本次实际输入与参数；新任务仍会核对预检与执行时的输入是否一致。

上传 ZIP 的处理也保存恢复来源。排队阶段中断可从校验一致的原 ZIP 重建输入；原包移动后可重新定位同内容文件，原包内容变化则需重新上传。已经开始的运行还会保存包内文件位置，临时解压目录被清理后仍可据此恢复。恢复只执行数据处理，不重发助手对话。

## 如何解读对比

- 选择的是具体历史记录，不会自动换成同名样品的最新结果。
- 差值为“右侧 − 左侧”；相对变化为“差值 / 左侧绝对值 × 100%”。左侧为零时不显示百分比。
- 缺失值不当作零；单位不同不直接相减。EIS 的 CPE n 改变会改变 Q 的量纲，因此此时 Q 仅并列显示。
- 参数、原始数据或辅助输入、软件和依赖版本变化均需结合实验条件解读。结果差异不一定仅由手动修改的参数造成。

## 报告的范围和保存内容

报告正文提供实验条件、计算设置、实际指标、质量信息和图表；附录记录完整参数、公式、输入文件 SHA-256、软件与计算依赖版本、运行父子关系。参数与输入证据独立保存到 SQLite，删除输出文件不会自动丢失运行配方。

全项目导出不受结果页分页影响；接口显式返回实际包含的运行和记录数量。无传统历史条目的 FE 运行也包含在全项目报告中。“所选结果”使用 `record_keys` 严格限定勾选的记录，不会连带导出同批其他样品；“单次处理”导出完整运行。接口另支持 `run_ids` 批量选择完整运行。

归档记录默认排除。已经删除部分结果的运行不再支持整次复算或整次报告，可选择剩余结果。删除最后一条普通运行历史时同步删除配方；永久删除项目同步清理其运行配方。托管原 ZIP 与恢复缓存仍被其他运行或项目引用时会保留，避免破坏其他项目的复算能力。

HTML 嵌入经过验证的本地栅格图；Markdown 配套保存图表资源。分享 Markdown 时需同时带上生成的资源目录。超出图表体积限制或已丢失的图表会在报告中说明。

## 助手建议与操作卡

在专业模式打开助手时，当前参数、数据类型、来源摘要及所选项目会随消息提供给助手。在项目结果页勾选记录后，可要求比较或生成所选结果报告。操作卡随会话保存，刷新后仍可打开。

- **参数建议**：先查看修改前后值和理由，再点击应用。保留当前输入文件与文件夹，原预检失效，正式处理前必须重新预检。参数或数据来源改变后，旧卡不能应用，需要重新获取建议。
- **比较结果**：使用明确的两条历史记录和左右顺序，跳转对比视图；不会自动换成同名样品最新版本。
- **历史复算**：带入建议参数，打开复算预检窗口；预检通过后才能开始新的运行。
- **结果报告**：跳转报告页并限定所选记录，点击生成后导出。

LSV 的数据特征分析复用正式解析、面积归一化、电位换算和 iR 补偿，返回 Tafel 候选区间的点数、log 电流跨度、斜率、R²、残差及局限。候选区间不是保证正确的动力学区间，应结合实验条件判断。缺少必要面积、源单位或列映射等信息时，助手先列出缺失项；当前其他数据类型尚不提供候选拟合。样品性能解读保留单位、记录及运行，不再把同名样品的处理版本直接平均或给出无依据的等级。

## 独立重复实验统计

在项目结果页勾选同类型结果，点击“重复实验统计”建立组；从“更多”中的重复实验入口重新打开保存的组。

1. 给组命名，核对每条结果对应的实验及采用版本。
2. 对不纳入统计的结果填写排除原因。同源数据或复算版本只能保留一个纳入项；旧记录来源不完整时，需要逐条确认独立性。
3. 核对计算口径。电位基准、归一化或拟合设置等关键条件不同或未记录时，查看逐条条件并明确确认可比较，之后才显示统计。成员、采用版本或条件改变会使原确认失效；单位或量纲不兼容的指标不能用确认绕过。
4. 查看每个指标的有效 n、均值及样本标准差。缺失值不当作零；只有一个有效点时标准差不显示。
5. 保存组，按指标查看单点、均值及 ±1 样本标准差，并下载 CSV 或 SVG。

组保存具体记录标识、确认状态和排除理由，不自动换用最新版本。删除成员记录后会标记缺失；永久删除项目时同步清理所属组。多人或多窗口同时修改时校验版本，避免旧窗口覆盖新修改。重复组描述统计不自动推断显著性或实验间的因果差异。

## 统一任务面板

顶部“任务”显示正在排队和运行的数量。打开后可按处理/AI、状态筛选并分页，查看阶段或逐文件进度、失败原因，返回对应结果或会话。任务记录保存在本地，刷新页面或切换标签后仍可查看；AI 阶段使用不定进度指示，不把请求阶段伪装成实际完成百分比。

“取消”适用于当前程序实例内可取消的任务。已确认且开始执行的助手写入操作不提供取消。中断的数据处理可进入已有“任务恢复”流程，核对输入后重新运行；不会自动重发助手对话。

## 已知边界

- 此功能从升级后的新运行开始记录完整证据。旧历史缺少参数、来源或指纹时如实显示“未记录”，不会拿当前默认值冒充历史值。
- 历史复算使用当前安装的计算引擎。版本、算法或依赖变化会提示，尚不自动启动旧版本环境，不能承诺跨版本结果逐位一致。
- 新版增加的处理参数需要明确填写，避免默默套用新默认值。
- 异常退出的任务通过“任务恢复”核验后重新运行；无法核实旧进程身份时需要人工确认，不能静默将其他活跃实例判定为中断。

接口详情见 [OpenAPI](openapi.yaml)：`/api/v1/runs`、`/api/v1/runs/{run_id}/replay-plan`、`/replay`、`/report`，以及 `/api/v1/history/compare` 和项目报告 POST 接口。
