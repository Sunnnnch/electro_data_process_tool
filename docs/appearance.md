# 外观设置

顶部“外观”集中管理界面风格、配色、字号、密度、背景网格和图表预览。设置即时应用并保存在当前浏览器，不需要重新启动，也不改变项目选择、数据文件、计算参数或已保存结果。

## 界面风格

| 选项 | 用途 |
| --- | --- |
| 现代简洁 | 柔和圆角和轻阴影，默认搭配实验室浅色，适合日常分析 |
| 纸感编辑 | 侧边目录、连续排列的表单与结果、细线分隔和衬线标题，默认搭配复古米白 |
| 柔和模块 | 顶部横向流程、大圆角模块与柔和阴影，默认搭配雾灰蓝 |
| 像素复古 | 直角控件和硬边阴影，默认搭配复古米白 |

界面风格决定布局、边角、边框和阴影，配色决定颜色。原来的实验室浅色、专业深海、高对比暗色作为配色继续提供。四种风格共用相同功能与工作流程；切换配色不会改变风格的布局与控件形状，切换风格也不会更改字号、密度或数据系列身份。窄窗口会将流程和结果重排为上下布局。

旧版选择“经典桌面”的界面会切换为“像素复古”。如果像素复古已有配色，继续使用其原有设置；尚未保存有效配色时，继承经典桌面配色。原经典桌面的当前或非默认配色保留在“此前保存的配色 → 原经典桌面配色”中，可手动应用；其他风格和阅读设置保持原样。

## 为不同风格选择配色

先选界面风格，再选配色。提供实验室浅色、专业深海、高对比暗色、复古米白、石板蓝、暖黑琥珀、雾灰蓝、掌机黄绿、灰紫九组预设，全部可搭配四种风格。例如纸感编辑可以使用高对比暗色，像素复古也可以搭配暖黑琥珀；“纸感”不限制为浅色背景。

选择“自选颜色”后，可用色块选择器或十六进制色值设置页面背景、面板背景、强调色、正文文字和窗口标题栏。配色即时应用到页面、按钮、标题栏、滚动条和助手。正文与面板背景对比不足时会显示提醒，可点击“自动匹配文字颜色”提高对比度；不会擅自覆盖用户选定的正文颜色。

每种风格分别记住自己的配色，切换回来会恢复上次选择。“跟随系统”位于配色区，根据系统亮暗偏好自动切换实验室浅色和高对比暗色，同时保留当前界面风格。手动选择固定配色后，不受系统亮暗变化影响。

旧设置自动迁移，保留当前配色和阅读设置。从仅有现代简洁、像素复古的版本升级时，原选择、自选颜色和备份继续保留，新增风格使用各自默认配色。旧主题中未被采用的自选颜色，会保留在“此前保存的配色”中；展开后点击即可应用到当前风格，切换或应用不会删除这份备份。

主操作使用强调色；刷新、搜索、更多等次操作使用中性色；删除操作使用危险色。任务继续显示文字状态，运行、成功、失败、中断各有对应颜色。禁用状态保留清晰文字并与可用控件区分，键盘焦点有可见轮廓。

数据分析助手入口使用烧瓶星光图标，默认采用月白灰底、深灰蓝文字和细边框。入口配色随当前配色自动变化：深海偏蓝灰、复古米白偏暖灰，暗色配色使用柔和深底与浅色文字。自选颜色同样适用，正常与悬停状态都会匹配清晰的文字颜色；纸感编辑保留方角和无阴影，像素复古保留直角与硬边阴影。

## 字号、密度和网格

- 界面字号：标准 14px、较大 16px、最大 18px。助手正文相应为 15px、17px、19px。
- 舒适密度：较宽松的控件、表格与分区间距，助手正文行高 1.7。
- 紧凑密度：缩小间距，助手正文行高 1.55；仍保留用户选择的字号。
- 背景网格：默认关闭，可独立打开。像素复古风格也遵从此开关。

助手长回答占据可用正文宽度，代码和宽表格可局部滚动并通过键盘访问。系统字体保证离线显示稳定。系统启用减少动态效果时，界面减少动画和过渡。

## 图表预览与导出

“跟随主题”使重复实验统计的矢量预览使用当前背景、轴线和文字配色；“论文白底”始终采用白纸预览。原始测量使用蓝色圆点，均值使用绿色菱形及误差条；颜色、点形、数据坐标不随主题改变，暗色预览增加轮廓以便辨认。

已经生成的比较 PNG 图像放在明确的白底图纸区域展示，保留原始图像配色。主题不修改原图，也不重新运行计算。重复组 CSV/SVG 导出与主题无关，SVG 始终保持白底；导出中的均值也采用菱形。

## 保存和恢复默认

设置保存在当前浏览器的本地存储中。“恢复当前风格配色”只恢复上表所列的当前风格默认配色；其他风格的选择、旧配色备份及阅读设置保持不变。弹窗底部“恢复默认”清除四种风格的配色选择和旧配色备份，并恢复现代简洁、实验室浅色、标准字号、舒适密度、关闭网格和图表跟随主题。若浏览器不允许保存外观设置，界面会说明更改只在本次页面生效。

外观变化可以关闭弹窗后直接继续工作。按 Escape 关闭外观弹窗，焦点返回原入口。
