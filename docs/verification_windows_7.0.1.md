## 完成内容

- “客户端 → 环境自检”：检查系统版本、架构、WebView2、.NET Framework 和数据目录读写；提供中英文、重新检查及可复制诊断。
- 启动失败显示可选择和复制的原生诊断。运行库不适用时保留浏览器回退；数据目录问题单独提示。已经运行的实例优先唤起。
- 源码和冻结客户端均可导出诊断到新文件，不覆盖原报告。诊断不自动上传，不包含模型密钥或实验内容；目录路径可能包含账户名。
- 标准安装包、内含 WebView2 的离线包、便携 ZIP 使用不同文件名。离线依赖需验证微软签名、签名载荷中的实际 Runtime 版本和 SHA-256，再嵌入安装包；不会在构建时运行该依赖安装程序。
- GitHub 手动发布流程支持显式开启离线包，核对准确提交、版本、签名和依赖清单。已公开版本及含旧附件的草稿会被拒绝，保留原附件。
- 新包包含最新助手烧瓶星光图标、F 月白灰配色及主题联动。
